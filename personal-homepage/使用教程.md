# 个人学术主页修改与发布教程

当前页面采用白底学术主页样式，和师兄页面的整体结构一致。你只需要替换内容，不需要理解构建系统。

## 1. 本地调试流程

1. 用 VS Code 打开 `personal-homepage` 文件夹。
2. 双击打开 `index.html`。
3. 修改 `site.config.js` 后按 `Ctrl + S` 保存。
4. 回到浏览器按 `F5` 刷新。

如果浏览器没有自动更新，按 `Ctrl + F5` 强制刷新。

## 2. 每个文件负责什么

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面骨架和顶部导航 |
| `site.config.js` | 姓名、简介、项目、论文、荣誉等全部内容 |
| `app.js` | 把配置内容显示到页面上的逻辑 |
| `styles.css` | 字体、颜色、间距、移动端布局 |
| `assets/` | 头像和论文、项目配图 |

## 3. 修改个人信息

打开 `site.config.js`，找到 `profile`：

```js
profile: {
  name: "CHANGXIN LI",
  nameZh: "你的中文名",
  avatar: "assets/avatar-placeholder.png",
  intro: "I am a Ph.D. student at Your University...",
  email: "your-name@example.edu.cn",
  socials: [
    { icon: "github", label: "GitHub", href: "https://github.com/your-name" },
    { icon: "scholar", label: "Google Scholar", href: "https://scholar.google.com/" },
    { icon: "bilibili", label: "Bilibili", href: "https://space.bilibili.com/" },
    { icon: "mail", label: "Email", href: "mailto:your-name@example.edu.cn" }
  ]
}
```

修改以下字段：

- `name`：英文名。
- `nameZh`：中文名。
- `intro`：个人简介。链接可以写成 `[南方科技大学](https://www.sustech.edu.cn/)`。
- `email`：邮箱。
- `socials`：社交链接，不需要的整项删掉。

## 4. 修改研究概览和研究项目

研究概览在 `overview`：

```js
overview: {
  title: "Research Overview",
  text: "在这里写研究方向的总体介绍。",
  images: [
    {
      src: "assets/roadmap-fig12.png",
      caption: "图片说明 [Reference](https://pubs.acs.org/doi/10.1021/acsnano.2c12606)"
    }
  ]
}
```

Research Overview 下方的图片现在支持翻页。需要多张图片时，在 `images` 数组中复制一组大括号并添加新的 `src`、`alt` 和 `caption`。

项目在 `highlights.projects` 中。每个项目包括：

```js
{
  title: "1. Project Title",
  summary: "项目简介",
  images: [
    { src: "assets/project-grid.png", caption: "图 1 说明" },
    { src: "assets/project-signal.png", caption: "图 2 说明" }
  ],
  citation: "作者, 论文标题. 期刊, 年份. [PDF](#)"
}
```

需要增加项目时，复制一整个大括号，并在前一个项目后加上英文逗号。

## 5. 修改论文

论文位于 `publications.items`：

```js
{
  image: "assets/project-grid.png",
  title: "论文标题",
  authors: "Your Name*, Coauthor One*, Corresponding Author",
  venue: "Nature Machine Intelligence",
  year: "2026",
  status: "Published",
  link: "https://doi.org/你的论文",
  pdf: "assets/你的论文.pdf"
}
```

把 PDF 文件放进 `assets` 文件夹后填写 `pdf`。没有 PDF 时留成空字符串：

```js
pdf: ""
```

## 6. 修改荣誉、技能和兴趣

- `honors.items`：`date`、`title`、`detail`。
- `skills.items`：`title`、`detail`。
- `interests.text`：个人兴趣介绍。
- `interests.videos`：需要嵌入 Bilibili 视频时，填写视频的 `bvid`。

例如：

```js
videos: [
  { bvid: "BV1xxxxxxxxx", title: "视频说明" }
]
```

## 6.1 设置留言板

页面底部的 `guestbook` 有两部分：

1. 访客留言表单：需要填一个能接收邮件的 `formEndpoint`。模板默认使用 FormSubmit，请把：

```js
formEndpoint: "https://formsubmit.co/your-name@example.edu.cn"
```

改成你自己的邮箱地址，例如：

```js
formEndpoint: "https://formsubmit.co/yourname@hit.edu.cn"
```

第一次有人留言时，FormSubmit 会向该邮箱发送激活邮件，激活后访客留言才会正常送达。

2. 精选留言展示：把你想公开的留言放入 `approved`：

```js
approved: [
  {
    name: "Visitor Name",
    date: "2026-09-08",
    message: "这里写访客留言内容。"
  }
]
```

只有写入 `approved` 的留言会显示在页面上，这样你可以自己选择性发布。

## 7. 替换图片

建议直接保持文件名并替换原图：

| 图片 | 替换内容 |
| --- | --- |
| `assets/avatar-placeholder.png` | 个人正式照片 |
| `assets/project-grid.png` | 研究配图一 |
| `assets/project-robot.png` | 研究配图二 |
| `assets/project-signal.png` | 研究配图三 |
| `assets/favicon.png` | 浏览器小图标 |

建议尺寸：

- 个人照片：640 × 780。
- 项目或论文配图：800 × 500。

## 8. 修改样式

页面结构已经按照参考页面写好。颜色和文字主要位于 `styles.css` 开头：

```css
:root {
  --bg: #ffffff;
  --text: #2c3e50;
  --muted: #5f7180;
  --link: #0984e3;
  --line: #eaecef;
  --nav-height: 58px;
  --page-width: 1120px;
}
```

常用的实时调试方法：

1. 在 Chrome 或 Edge 中打开 `index.html`。
2. 按 `F12`。
3. 点击左上角的“选择元素”图标。
4. 在页面上选择想修改的元素。
5. 在右侧 `Styles` 面板中修改颜色、字号或间距。
6. 满意后把数值写回 `styles.css`。

## 9. 常见错误

### 页面空白

按 `F12` 打开 `Console`。如果提示 `SyntaxError`，通常是 `site.config.js` 缺少英文逗号、引号或括号。

### 图片不显示

检查 `assets` 中的文件名和 `site.config.js` 中的路径是否完全一致。

### 手机端显示过大或换行异常

在开发者工具中点击手机图标，选择不同宽度预览。对应样式在 `styles.css` 的 `@media` 部分。

## 10. 发布到 GitHub Pages

1. 注册并登录 GitHub。
2. 新建仓库，仓库名必须是 `你的用户名.github.io`。
3. 选择 `Public`。
4. 把 `personal-homepage` 文件夹内的文件上传到仓库根目录。
5. 打开仓库的 `Settings -> Pages`。
6. `Branch` 选择 `main`，目录选择 `/ (root)`。
7. 点击 `Save`，等待约 1 到 2 分钟。
8. 访问 `https://你的用户名.github.io/`。

以后每次修改后重新提交，网站会自动更新。
